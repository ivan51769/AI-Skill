# AI Skill Collection

This repository contains open, reusable Codex skills.

## Skills

- [`codex-native-installer`](skills/codex-native-installer/) - Windows helper skill that downloads the official Codex app package from Microsoft Store package links and installs it with `Add-AppxPackage`.

## Privacy Notes

The published copy excludes local runtime artifacts such as `node_modules`, downloaded MSIX packages, logs, and machine-specific paths.
